I'm Michael! I am nerdy about a lot of stuff, and want to start writing about it. So this blog will be the place to host this blog.

This blog, and furthermore, my homepage aren't fancy tech-wise. The blog is simply put together using Markdown, being put together into a nice package using [Astro](https://astro.build).

We are deploying this static page on [Cloudflare Workers](https://workers.cloudflare.com). Nothing fancy, gets the job done, and that for free.

At the time of writing, the complete bundle size comes in at 23.1KB, this includes a full IBM Plex Mono latin subset.

I might be writing more in the future, so stay tuned!
